
## 1. 슬롯 태그 (Slot Tags)
* **Z**: 현재 상황 / 현상
* **T**: 시간 / 흐름
    * `T:1400`: 14시 00분 (절대 시간)
    * `Tp`: 과거
    * `Tf`: 미래
    * `Tn`: 현재
    * `T:flow`: 진행형
    * `Td:3h`: 3시간 동안 지속
    * `T:inf`: 영구적 상태
* **K**: 원인 / 전제
* **F**: 결과 / 작용
* **N**: 생각 / 가치 판단

## 2. 식별자 태그 (ID Tags)
* **I**: 화자 (나)
* **Y**: 청자 (너)
* **X**: 제3자 / 외부 객체

## 3. 논리 게이트 (Logic Gates)
* **>** : 인과관계의 흐름 (A 때문에 B가 됨)
* **<>**: 상호 영향 (A와 B가 서로 주고받음)
* **~>**: 지연된 인과 (A가 시간이 흐른 뒤 B를 유발함)
* **|** : 선택 (A 혹은 B 중 하나)
* **=** : 동시 발생 (A와 B가 동시에 일어남)
* **!** : 즉각적인 대응이 필요한 데이터 (경고/위험)
* **?** : 데이터 확인 요청 (질문)
* **,** : 문장 끊기와 동시에 병렬
* **;** : 목적 전달 (데이터의 목적을 나타내는 꼬리표)
* **~** : 부정 (~가 아니다, ~이 없다)

## 4. 벡터 및 확장 태그 (Vector Tags & Suffix)
### 기본 벡터
* **+**: 확장, 상승, 강화
* **/**: 축소, 하락, 약화
* **_**: 반전, 모순, 거부
* *****: 설명하기 힘든 모호한 상태

### 지속성 및 변동성 지수 [(1-5) × 10 + (1-5)]
* **십의 자리 (지속성)**: 1(10분↓), 2(10~30분), 3(30~1시간), 4(1~3시간), 5(3시간↑)
* **일의 자리 (변동성)**: 1(안정), 2(살짝 불안), 3(불안), 4(빠르게), 5(매우 빠르게)
* **@**: 대상 지정 (Target)
    * 예시: `@Y:iRm55+` (너를 향한 짜증이 3시간 이상 매우 빠르게 상승함)

## 5. 범위 및 경계 태그 (Scope Tags)
* **()**: 내부, 본질, 비공개 데이터 (내면의 생각)
* **[]**: 외부, 표면, 공개 데이터 (겉으로 드러난 행동)
* **{}**: 논리적 그룹핑 (연산 우선순위 지정)
* **Md**: 경계, 상호작용 지점 (사회적 규칙, 검열 등)
    * 예시: `(iRm+) > Md{Pi:Xc} > [aZm]` (내면의 짜증을 규칙에 의해 검열하여 겉으로 동의함)

## 6. 확신도 및 인류학 태그 (Certainty & Humanity Tags)
### 확신도 (Certainty)
* **Xc**: 확정된, 변하지 않는, 진리
* **Uc**: 가변적인, 불확실한, 추측

### 인류학 태그 (Humanity)
* **Ht**: 논리적 근거 없는 직관적 느낌
* **St**: 공감 (상대의 상태를 함께 느낌)
* **Lt**: 가능성과 상상

## 7. 주요 카테고리 (Primary Categories)
* **Vg (결핍/필요)**: `bVg`(육체적), `mVg`(정신적), `rVg`(물리적)
* **Lg (인지/지식)**: `mLg`(기억), `iLg`(외부 정보), `cLg`(논리 추론), `vLg`(사실 확인 완료)
* **Kg**: 충돌/대립, 소란, 오류, 마찰
* **Sg (해소/획득)**: `bSg`(육체적), `mSg`(정신적), `rSg`(물리적)
* **Dg**: 위계/주체 (상급자, 시스템)
* **Sbg**: 하위/객체 (하급자, 유닛)
* **Pi**: 약속, 계약, 규칙
* **Zm (평온/수용)**: `sZm`(나른함/휴식), `aZm`(동의/타당함), `fZm`(충족감)
* **Rm (분노/거부)**: `iRm`(짜증/마찰), `fRm`(공포/위협), `sRm`(슬픔/상실)
* **Vl**: 중요, 가치 존재
* **Hs**: 내 것, 연결됨, 소유함

## 8. 필터 태그 (Filter Tags - fitr)
* **#Burnout**: `{T:flow + Kg:High + (Rm+)}`
* **#Flow**: `{T:flow + cLg + (fZm+)}`

## 9. 표현 예시 (Examples)
1.  `T:flow, {X:Dg > I:Sbg} ~> (@Y:iRm40+), [aZm:Xc] ; Z`
    * 진행형 상황. 상급자 X가 나에게 영향을 주어 내면의 짜증이 커지고 있으나, 겉으로는 확정된 동의를 보임.
2.  `I : #Burnout {bVg:90 + (Ht:sRm+)} ! ; Lg`
    * 나의 번아웃 상태. 육체적 피로가 90이며 이유 모를 슬픔이 내면에서 상승 중인 위험 데이터.
3.  `Tn, {Y(mLg > sRm)} > I(St) = [sZm], (Lt:St) ; N`
    * 현재 너의 과거 기억이 유발한 슬픔을 내가 공감하며, 외적으로는 평온을 유지하고 내적 해결을 상상함.
4.  `K(cLg#) ~> I{#Burnout + (sRm50)} ! ; F`
    * 준비한 프로젝트 실패(논리 연산 오류)로 인해 깊은 상실감과 번아웃에 빠진 결과.
5.  `~aZm`: 동의하지 않음 / `~Has`: 내 것이 아님.
